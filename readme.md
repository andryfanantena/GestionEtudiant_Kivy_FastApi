A Propos de l'application :

Le principe est simple, l'utilisateur entre les noms des étudiants. clique sur le bouton démarrer la présence. et voila la présence est fait.

Maintenant on peut accéder a la page présent qui affichera la liste des étudiants présents. De même pour les absents, on peut y accéder a la page en cliquant sur le bouton absent et on peut y consulter la liste des étudiants absents.

A chaque session de présence, la liste de chaque page se met a jour automatiquement.

Pour démarrer le serveur, il faut accéder a awesome-project et démarrer avec "uv run fastapi dev"
Et pour démarrer l'application il faut juste démarrer avec "python app.py"
